# PDv2 Round E / WP6 — three legendary nodes: respawn echoes, cursed craft, cursed quest — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. One Opus agent per task; the planner reviews between tasks (Sonnet, short) and does the docs, the client rebuild, the install and the vault.

**Goal:** Three new Forgotten Talents nodes at the far end of the tree, each a synthetic passive dummy aura whose **`EffectMiscValue` is a tag** consumers read (never the spell id): **respawn** (tag 76001, 2 ranks, value = rank: every ordinary kill in the procedural dungeon rises again as `value` echo copies that pay materials and Paragon XP but no currency), **cursed craft** (tag 76002, 5 ranks, +2/4/6/8/10 % cursed chance on crafted items), **cursed quest** (tag 76003, 5 ranks, the same on quest rewards). The nodes hang off the deepest node of the combat / crafting / questing branches, so they sit in the most expensive cost band, with `cost_mult` 200 (respawn) and 300 (the two curses).

**Architecture:** The FT importer's `--from-canonical` path gains an **extension contract**: `content/extra_nodes.json` (ids ≥ 2000) is merged after the canonical tree is loaded, spell records for the extension ranks are synthesised from a measured house template, and spell ids become **sticky** (`spell_id_map.json` is read-modify-written, new ids appended from 120860). Consumers are file-local ten-line readers of `GetAuraEffectsByType(SPELL_AURA_DUMMY)` matched on `GetMiscValue()`: PD spawns the echoes in `OnMobDied` through the existing `SpawnTaggedMob` with a new `isRespawnCopy` tag field; `mod-paragon-itemgen`'s `RollCursed` gains a `(Player*, CursedContext)` signature and adds the tagged amount to the percent chance. No cross-module include anywhere.

**Tech Stack:** Python 3 importer + unittest (FT), C++17 modules (`-Werror`, `codestyle-cpp.py`), AC 3.3.5 aura API, module world SQL (`spell_dbc` rows regenerated by `build_client_data.py`), hot-DBC client patch (script 30).

**Spec:** `docs/superpowers/specs/2026-09-10-pdv2-round-e-loot-talents-design.md` §3 T2 (D7 for the loot half). Recon with `path:line`: `.superpowers/sdd/wp6-recon.md`. Three deviations from the spec's sketch, all measured: (1) the synthetic spell template is 120733 (`DurationIndex` 0, levels 0 — not 21 / 1); (2) the Ebonhold `SpellIcon.dbc` is not on this box, so the three nodes use **stock** icons 221 / 335 / 3421 and the icon test stays at 83 (not 86); (3) the questing parent is **199** (`Hunter's Insight Milestone`, the end of the chain that starts with the quest-XP node 430) — the two readings of "deepest questing node" differ, this one is the deeper.
