## K1 — the alt-1 room's facade reserve (`48_gen_t1_blockkit.py`)

The alt-1 (platform) room reserved `PAD_FACADE_SLOTS` (8) placement slots for a pad facade ring
whenever the room carried a pad at all, and then spent **one** of them: Round B/B2 deleted the
33 yd boss pad, so the only pad left is the 2x2 centre pad, whose `add_pad_facades()` branch places
a single centred `house_d`. Seven reserved-and-unspent slots came straight out of the wall budget —
`per_side = (24 - 8) // 4 = 4` houses per wall instead of 5 — and the missing fifth house is the
bare street frontage the operator saw as a tower room with holes in its skyline. The fix makes the
reserve match the branch actually taken: two new module-level helpers, `pad_span_yd(fp)` (the span
expression `add_pad_facades` already measured itself with, factored out so the two cannot drift,
and written in the two-step `v0`/`v1` form because the one-step algebraic equivalent is a different
float on the real pad) and `pad_facade_reserve(fp)` (no pad -> 0, span >= `PAD_MIN_SPAN_YD` -> the
ring's 8, below it -> 1). The alt-1 call site now asks for `pad_facade_reserve(pad)`, so
`per_side = (24 - 1) // 4 = 5`. `PAD_FACADE_SLOTS` itself stays 8, `PLACE_K_W` stays 24, and no
record format changed. `KIT_VERSION` 26 -> 27.

## K2 — the MCNK do-not-fix-alpha flag, the edge pin, the wider feather (`51_texture_blockkit.py`)

The client's own alpha "fix" pass rewrites the last row and column of every MCNK alpha map unless
the MCNK header carries `0x8000` (`do_not_fix_alpha_map`), which is why the painter had to *pin*
row/column 63 to a constant — an asymmetric pin, so every block boundary showed a step of 10 of 15
in the floor blend. `retexture_mcnk()` now sets that bit as a read-modify-write of the one header
dword (the idiom `52_punch_kit_holes.py` already uses for `holes` and the low-quality texture map),
and `verify_file()` gained a per-MCNK gate that compares the produced dword against `input | 0x8000`
— one comparison that fails an MCNK which missed the bit *or* gained or lost any other. With the
flag on, the pin could go: `paint_block_alpha()` lost its `on_mcnk_edge` term and ramps every
walkable texel, the envelope gate lost the mirrored clause, and `FEATHER_TEXELS` went **4 -> 6**
(2.08 -> 3.13 yd), which the pin had been holding narrow. Alpha encoding is untouched — still raw
4-bit, `ALPHA_BYTES` 2048, `MCLY_FLAG_COMPRESSED` never set, `nLayers` 2 — so every ADT is still
1 143 375 B and no MCIN/MHDR rebuild was needed. The MCSH wall-band shadow stays off.

every walkable cell of every chunk of the staged kit — was a kit-26 capture, and against the v27

is therefore unchanged at `…:8410:;`, which is the independent check that the masks really held.

those same 14 rows' `patrolClear` / `patrolDu` / `patrolDv`.

## The script diffs, and the rule about them

The pipeline scripts live in `C:\wowstuff\ForgottenLand2.0\scripts`, which is **not** a git
repository — a diff against a dated backup is the only durable record of what changed. Backups
taken before this round's edits:

| Script | Backup |
|---|---|
| `48_gen_t1_blockkit.py` | `48_gen_t1_blockkit.py.pre_roundE_20260910` |
| `51_texture_blockkit.py` | `51_texture_blockkit.py.pre_roundE_20260910` |

Both diffs in this folder — `task-1-script48-pad-reserve.diff` and
`task-2-script51-alpha-pin-flag.diff` — are **cumulative against those `.pre_roundE_20260910`
backups**, not against each other and not against the Round A diffs beside them: each is a full
`diff -u <script>.pre_roundE_20260910 <script>` taken at the end of its task. Applying one to its
own backup reproduces the live script. The rollback path for a script is that backup, and the
rollback path for the kit is in `FLStream.ini`'s version ladder.
